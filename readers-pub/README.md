# readers-pub — Сайт ресторана

Локальная копия сайта [readerspub.ru](http://readerspub.ru/).

## Запуск

```bash
cd readers-pub
python3 server.py
```

Откройте: **http://localhost:8081** (сайт) и **http://localhost:8081/admin/** (админка).

## Бронирование

Брони переведены на **Яндекс Форму** (страница `bronirovaniestola.html`).
Как создать и подключить форму — см. `README-YANDEX-FORM.md`.
Заявки на банкет по-прежнему уходят в Telegram (см. `.env.bot` в корне проекта).

## Админка (`/admin`)

Каркас панели управления контентом сайта: логин, дашборд, редактор текстов
главной, настройки, медиа-библиотека, просмотр броней.

- Логин по паролю. Локальный пароль по умолчанию: `readerspub-admin`.
  Задайте свой через переменную окружения `ADMIN_PASSWORD`.
- ⚠️ **Безопасность:** авторизация — учебный каркас (пароль по HTTP). Перед
  боевым запуском вынесите админку за настоящую аутентификацию (HTTPS, хеш
  пароля/сессии или OAuth).
- Тексты хранятся в `content.json`, сайт читает их через `content-loader.js`
  (элементы с атрибутом `data-content="path"`). Сейчас связан hero-блок главной.

## Меню (`menu.html`)

Страница меню — это **сканы страниц** из вёрстки заведения, лентой вниз:
на телефоне одна страница под другой, на ПК — по две в ряд.
Клик по странице открывает её крупно, второй клик приближает, стрелки
и свайп листают, Esc закрывает.

Порядок: **кухня → напитки и бар → осеннее меню**.

Файлы лежат в `assets/menu/`, по две версии на страницу:

| Файл | Для чего |
|---|---|
| `menu-0X-....webp` | основной, ~1400 px по ширине (ПК и крупный просмотр) |
| `menu-0X-...-760.webp` | уменьшенный, 760 px (телефоны) |

### Как заменить или добавить страницу меню

1. Сохранить новый скан (JPG/PNG, от 1400 px по ширине).
2. Сделать обе версии:

```bash
python3 - <<'PY'
from PIL import Image
src, name = "путь/к/скану.jpg", "menu-08-novaya-stranica"
im = Image.open(src).convert("RGB")
im.save(f"assets/menu/{name}.webp", "WEBP", quality=84, method=6)
sm = im.copy(); sm.thumbnail((760, 10000), Image.LANCZOS)
sm.save(f"assets/menu/{name}-760.webp", "WEBP", quality=82, method=6)
print(im.size)
PY
```

3. В `menu.html` скопировать блок `<a class="scan">`, подставить имена файлов,
   `alt` и реальные `width`/`height` (их печатает скрипт).

Старая текстовая версия меню сохранена как `_menu-text-old.html.bak`
(на сайте не используется).

## Баннер акций — ТЗ для маркетолога

Раздел «Акции» на главной — это **одно фото целиком**, без текста и кнопок
поверх. Нужны ровно **две карточки**, третьего формата на сайте нет:

| Устройство | Размер, px | Соотношение |
|---|---|---|
| **ПК и планшет** (шире 860 px) | **1920 × 1440** | 4:3, горизонтальная |
| **Телефон** (860 px и уже) | **1080 × 1440** | 3:4, вертикальная |

Это один и тот же формат 4:3 — на ПК лежит, на телефоне стоит.

Пропорции зафиксированы в CSS: фото **не обрезается и не растягивается**
ни на каком размере экрана — меняется только масштаб. Углы прямые.
Баннер сам ужимается, если не помещается в экран по высоте, и на
телефоне стоит с отступом 16 px от краёв.

Весь текст акции — прямо на картинке: поверх ничего не накладывается,
затемнения нет, значит надписи будут видны как есть. Контакты и кнопку
«Забронировать» на баннер выносить не нужно, они рядом на странице.

Где стоит: на ПК — **перед разделом бронирования**; на телефоне раздел
бронирования скрыт и баннер стоит на его месте (бронь на телефоне —
кнопка «Бронь» в нижней панели и «Забронировать стол» на первом экране).

### Как поставить баннер

1. Сохранить обе карточки как `promo-desktop.webp` (1920×720) и
   `promo-mobile.webp` (1080×1350) в папку `assets/promo/`.
2. В `index.html` найти секцию `id="promo"` и раскомментировать блок
   `<picture>` — там уже прописаны оба файла и переключение по ширине.
3. Если баннер должен вести на страницу акции — обернуть `<picture>`
   в `<a href="...">`.

Пока файлов нет, на месте баннера ровный серый прямоугольник.

## Баннеры главной страницы (hero) — ТЗ для маркетолога

Сейчас баннеров нет: на их месте серый фон-заглушка.

Главный экран показывает **свой баннер под каждое устройство** — один
горизонтальный кадр нельзя просто обрезать под телефон, от него остаётся
узкая полоска. Поэтому макеты нужны в трёх форматах:

| Устройство | Размер, px | Соотношение | Ориентир |
|---|---|---|---|
| **ПК** | **1920 × 1080** | 16:9 | как превью YouTube |
| Планшет | 1536 × 2048 | 3:4 | портрет |
| **Мобилка** | **1080 × 1920** | 9:16 | как сторис |

Ключевые — **ПК и мобилка**, планшет между ними.

### Что учесть в макете

- **Безопасная зона.** Поверх баннера ложится текст и кнопки: на ПК —
  по центру, на телефоне — логотип и меню в столбик по центру. Не
  размещайте важное (лица, надписи, логотип) в центре кадра — держите
  сюжет по краям или делайте центр спокойным.
- Баннер **затемняется** полупрозрачной подложкой ради читаемости текста,
  а на телефоне ещё и размывается. Мелкие детали и текст на самом баннере
  не читаются — их лучше не использовать.
- Формат файла: **JPG или PNG**, от 3000px по длинной стороне
  (скрипт сам сожмёт в WebP и сделает все три кропа).

### Как поставить баннер на сайт

Из **одного** исходника скрипт делает все три версии:

```bash
python3 tools/make-hero-crops.py путь/к/фото.jpg --name hero-1 --focus 0.5 0.4
```

`--focus X Y` — точка кадра (в долях 0..1), которая должна остаться видимой
при обрезке. По умолчанию центр; если главное в верхней части кадра — ставьте
Y меньше (например `0.35`).

Файлы появятся в `assets/hero/`. Затем в `index.html` внутри
`<div class="hero-photos">` раскомментируйте блок `<picture>` (там уже лежит
образец). Несколько блоков `<picture>` = слайдер из нескольких баннеров;
у первого оставьте класс `is-active`.

## Структура

- `server.py` — сервер + API (брони/банкет, `/api/content`, `/api/admin/*`)
- `content.json` — контент сайта (правится админкой)
- `content-loader.js` — подстановка контента на страницы сайта
- `admin/` — админ-панель (`index.html`, `admin.css`, `admin.js`)
- `index.html` — главная
- `bronirovaniestola.html` — бронирование стола (Яндекс Форма)
- `menu.html` — меню (сканы страниц, см. раздел «Меню»)
- `standup.html` — стенд-ап
- `privacy.html` — политика конфиденциальности
