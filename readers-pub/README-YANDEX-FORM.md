# Брони через Яндекс Форму + Яндекс Таблицу

Схема: гость заполняет форму на сайте → заявка автоматически падает **строкой
в Яндекс Таблицу** → приходит уведомление на почту и в Telegram.

Бесплатно, сервис российский, таблицу видят все сотрудники сразу.

Страница `bronirovaniestola.html` уже подготовлена: там стоит заглушка,
которая ждёт только **ID формы**.

---

## Шаг 1. Создать форму

1. Зайти на **forms.yandex.ru** под аккаунтом заведения.
2. **Создать форму** → пустая.
3. Название: `Бронирование стола — Бар Читателей`.

## Шаг 2. Добавить вопросы

| Вопрос | Тип ответа | Обязательный |
|---|---|---|
| Ваше имя | Короткий текст | да |
| Телефон | Телефон | да |
| Дата | Дата | да |
| Время | Время | да |
| Количество гостей | Число (или список 1–10+) | да |
| Пожелания | Длинный текст | нет |
| Согласен с обработкой персональных данных | Флажок | **да** |

⚠️ Последний пункт обязателен по 152-ФЗ: собираем имя и телефон.
В подписи к флажку дайте ссылку на политику: `https://readerspub.ru/privacy.html`

## Шаг 3. Оформить под бренд

**Дизайн → Оформление**, подставить цвета из брендбука:

| Что | Цвет |
|---|---|
| Фон формы | `#2B3155` (тёмно-синий) |
| Текст | `#FDFCF2` (кремовый) |
| Кнопка отправки | `#773345` (винный) |
| Акценты / ссылки | `#95D4F2` (голубой) |

Туда же загрузить логотип: `assets/logo-chitateley-white.png`.
Текст кнопки отправки: «Забронировать».

## Шаг 4. Подключить таблицу  ← ради этого всё

1. Вкладка **«Интеграции»**.
2. Включить **«Сохранять ответы в Таблицу»**.
3. Яндекс создаст таблицу на Диске — каждая заявка станет новой строкой.
4. Открыть таблицу → **«Поделиться»** → выдать доступ хостес и управляющему.

## Шаг 5. Настроить уведомления

В той же вкладке «Интеграции» → «Уведомления»:
- письмо на почту заведения при каждой заявке;
- (по желанию) уведомление в Telegram — чтобы хостес видел бронь сразу.

## Шаг 6. Опубликовать и забрать ID

1. Нажать **«Опубликовать»**.
2. Скопировать ссылку вида:
   `https://forms.yandex.ru/u/`**`68f0abc123def456`**`/`
3. Жирная часть между `/u/` и `/` — это **ID формы**.

## Шаг 7. Подключить к сайту

Открыть `bronirovaniestola.html`, найти строку:

```js
const YANDEX_FORM_ID = "";
```

и вписать ID:

```js
const YANDEX_FORM_ID = "68f0abc123def456";
```

Сохранить, обновить страницу — вместо заглушки появится форма.

---

## Проверка

1. Открыть `/bronirovaniestola.html` — форма встроилась.
2. Отправить тестовую заявку.
3. Убедиться: строка появилась в Таблице, уведомление пришло.
4. Удалить тестовую строку из таблицы.

## Если форма не появилась

- ID скопирован не полностью (нужна только часть между `/u/` и `/`).
- Форма не опубликована — проверьте кнопку «Опубликовать».
- В настройках доступа формы должно стоять «Доступна всем по ссылке».
